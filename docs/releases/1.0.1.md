# ReflowPress 1.0.1 Release Notes

**Release Date:** 2026-11-19  
**Status:** Security Release  
**Tag:** `v1.0.1`

ReflowPress 1.0.1 is a security release. **Everyone running 1.0.0 should upgrade.** It fixes ways a crafted EPUB, PDF, sync bundle or network peer could read or overwrite files, reach the network, or hang the app. There are no new features. A few behaviour changes come with the fixes; they are listed under [Behaviour changes](#behaviour-changes) below.

---

## Security fixes

### Desktop app

- **The reader can no longer touch files you did not choose.** In 1.0.0, code running inside the reader window (for example through a malicious book that got past the content sanitizer) could ask the app to read or write any file your user account can access. The app now accepts a file or folder only after you pick it in a system dialog, open it from the command line, or add it to your library.
- The reader window is served from a private `app://` address instead of `file://`, with a strict Content Security Policy. Network access, permission prompts, navigation, pop-ups and embedded web views are blocked inside it.
- Sharing your library on the local network, and syncing with a WebDAV server for the first time, now ask for confirmation in a system dialog.
- Electron is updated to 44.11.4 for the latest Chromium security fixes.

### Network and sync

- **OPDS server:** websites can no longer read your catalog through DNS rebinding. In LAN mode, every URL now contains a random access token that changes each time the server starts. File serving no longer leaks file handles.
- **WebDAV and OPDS clients:**
  - Response sizes are capped and every request has a time limit.
  - Credentials are never sent to a different host.
  - WebDAV no longer follows redirects.
- **Sync:**
  - Incoming sync data is validated record by record.
  - Folder locks can no longer be removed by the wrong machine.
  - A deletion dated far in the future can no longer erase records permanently.
  - A sync no longer clears the file paths of books already in your library.
- **USB transfer:** files are written only inside the device. A link planted on the device cannot redirect writes, and transfer never overwrites a file that appeared after planning.

### Books, PDFs and exports

- **Inspection and repair:**
  - Compressed archives ("zip bombs"), oversized PDFs, and patterns that made scanning take minutes are now bounded.
  - Repair never overwrites an existing file.
- **HTML, PDF and Markdown export:**
  - Scripts, event handlers and remote resources are removed with an allowlist sanitizer, which replaces a pattern-based one that could be bypassed.
  - Exported HTML carries a strict Content Security Policy.
  - Markdown output escapes everything it copies from the book.
- **PDF export** renders inside Chromium's operating-system sandbox, with JavaScript disabled and no network access.
- **Annotations:**
  - Imported annotations are validated field by field.
  - Exported annotations are escaped.
- **Command line:** printed output is stripped of terminal control sequences that a book or feed could use to tamper with your terminal.

### Other fixes

- `reflowpress opds serve` now keeps running until you stop it (Ctrl+C). Before, it exited immediately.
- `reflowpress restore` keeps the file paths of books already in your catalog.
- A malformed link in a book's table of contents no longer makes the whole book unreadable.

## Behaviour changes

1. **LAN OPDS URLs change on every start.** When you share your library on the network, copy the full URL the app or CLI shows (`http://<address>:<port>/<token>/...`). Old bookmarks in reading apps stop working after a restart. Without LAN mode, requests sent to any host name other than `127.0.0.1`, `localhost` or `[::1]` are answered with `421 Misdirected Request`.
2. **WebDAV no longer follows redirects.** If sync now fails with HTTP 301, 302, 307 or 308, enter the final URL, often the `https://` form or the path with a trailing `/`. URLs with a username or password embedded in them are refused; use the username and password fields instead.
3. **PDF export requires Chromium's sandbox.** On Ubuntu 23.10 and later, and when running as root, the sandbox cannot start by default and export stops with an error. Either allow unprivileged user namespaces:

   ```sh
   sudo sysctl -w kernel.apparmor_restrict_unprivileged_userns=0
   ```

   or explicitly run without the sandbox, accepting reduced isolation, for example inside a container that is already isolated: `REFLOWPRESS_CHROMIUM_NO_SANDBOX=1`. See [Troubleshooting](https://github.com/bosatsu25/ReflowPress/blob/main/docs/troubleshooting.md).

4. **Exports are fully offline.** Remote images, media, stylesheets and fonts are removed from HTML and PDF exports. Links to web pages and email addresses are kept.
5. **Stricter EPUB checks.** Inspection and repair now refuse archives that the reader also refuses:
   - corrupt entries (CRC or size mismatch)
   - duplicate entry names
   - encrypted entries
   - archives larger than 128 MiB, or entries over 16 MiB when repairing

   These now appear as findings (`EPUB-CONTAINER-006`, `EPUB-SEC-003`) instead of errors. New PDF findings `PDF-STRUCT-003` and `PDF-STRUCT-004` report files or content beyond the inspection limits.

6. **Choosing folders.** Sync, backup and device paths are chosen with a dialog. They can no longer be typed into the window.

## Known limitations

The limitations listed for [1.0.0](https://github.com/bosatsu25/ReflowPress/blob/main/docs/releases/1.0.0.md) still apply: unsigned binaries, MTP devices not mounted directly, no Media Overlay playback, no DRM circumvention, and no background auto-update. In addition:

- **Inspection runs in the app's main process.** Inspecting a deliberately crafted EPUB can still freeze the app for several seconds. Memory and time are bounded, so it does not crash.

The design behind these fixes is described in [ADR 0011](https://github.com/bosatsu25/ReflowPress/blob/main/docs/adr/0011-desktop-trust-boundary.md) and [SECURITY.md](https://github.com/bosatsu25/ReflowPress/blob/main/SECURITY.md).

## Verification & Integrity

Every release artifact is listed in `SHA256SUMS.txt`. Verify your download before running it:

```powershell
Get-FileHash -Algorithm SHA256 .\ReflowPress-Setup-1.0.1.exe
```

```sh
sha256sum ReflowPress-1.0.1-linux-x86_64.AppImage
```
