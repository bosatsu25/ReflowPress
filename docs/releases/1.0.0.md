# ReflowPress 1.0.0 Release Notes

**Release Date:** October 2026  
**Status:** Stable Release  
**Tag:** `v1.0.0`

ReflowPress 1.0.0 marks the culmination of 10 engineering milestones, evolving from a document converter into a **free, local-first electronic book workbench**. ReflowPress empowers readers, researchers, and book collectors to read, organize, inspect, safely repair, search, annotate, and export EPUB and PDF publications without cloud lock-ins or privacy compromises.

---

## Highlights

- **Shared Publication Core**: Single robust parser understanding EPUB 2 and EPUB 3 publications, navigation trees, and resource boundaries.
- **Desktop Reader**: Sandboxed reflowable EPUB viewing, native PDF rendering with zoom controls, customizable typography, and reading state persistence.
- **Digital Library Catalog**: Recursive folder scanning with incremental indexing, cover caching, custom shelves, and sub-10 ms query performance for 1,000+ books.
- **Reading Tools**: W3C Web Annotation compliant hybrid locators, highlights, notes, in-book search, and Markdown/HTML/JSON export.
- **Japanese Typography & Accessibility**: Vertical writing mode (`vertical-rl`), strict kinsoku rules, tate-chu-yoko, WCAG 2.2 AA keyboard operability, and screen reader announcements.
- **Export Workbench**: Safe, offline EPUB-to-PDF, standalone HTML, and GFM Markdown conversion with deterministic naming and transaction rollbacks.
- **Quality & Safe Repair**: Granular diagnostic rule engine (`EPUB-*`, `PDF-*`), PDF Quality Gate, non-destructive repair with `.provenance.json` audit trails.
- **Interoperability & Data Portability**: OPDS 2.0 streaming catalog, 3-way sync engine, WebDAV support, portable backup bundles, and USB e-reader transfer (Kindle, Kobo, PocketBook).
- **Hardened Runtime**: Crash recovery with active session recovery banners, forward schema migration defense (`UpgradeRequiredError`), and Electron binary fuses.

## Known Limitations and Boundaries

To ensure complete transparency and user trust, ReflowPress 1.0 documents the following operational boundaries:

1. **Unsigned Binaries**: Open-source builds are distributed without commercial EV code-signing certificates. On Windows and macOS, users must acknowledge standard SmartScreen or Gatekeeper security prompts upon initial launch (see [Code Signing Policy](../code-signing.md)).
2. **MTP Device Transfer Boundary**: Physical e-readers connecting via Media Transfer Protocol (MTP) rather than standard USB Mass Storage are not directly mounted by the desktop client. Users must mount MTP devices via their operating system file manager or transfer files to standard filesystem directories.
3. **Media Overlays Playback**: EPUB 3.3 Media Overlay (SMIL 3.0) documents and audio references are fully inspected and validated by the diagnostic engine, but integrated synchronized audio playback controls in the reader UI are planned for post-1.0.
4. **DRM Protected Content**: ReflowPress strictly respects intellectual property boundaries and does not decrypt or circumvent DRM protection schemes. Publications protected by proprietary DRM are flagged with informative notices.
5. **No Background Auto-Update**: In alignment with our local-first and zero-telemetry philosophy, ReflowPress will not poll the network or silently auto-update. New releases must be downloaded and verified manually (see [Update Policy](../updates.md)).

## System Requirements

- **Windows**: Windows 10 (64-bit) or Windows 11.
- **macOS**: macOS 12 (Monterey) or later (Intel x64 or Apple Silicon arm64).
- **Linux**: Ubuntu 22.04+, Debian 12+, Fedora 38+, or compatible modern Linux distributions (glibc 2.35+).
- **Memory**: Minimum 2 GB RAM (4 GB recommended for large PDF rendering).
- **Storage**: ~250 MB free disk space for application installation.

## Verification & Integrity

Every official release artifact is cataloged in `SHA256SUMS.txt`. Always verify the integrity of your downloaded installer before running:

```powershell
Get-FileHash -Algorithm SHA256 .\ReflowPress-Setup-1.0.0.exe
```
